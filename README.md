# NETWORKWALKS-B083-WK3-PM1-PM2-PASSWORD-CRACKING

## Week 3 — Password Cracking

This repository documents the practical work completed for Week 3, covering password cracking of protected PDF files using **John the Ripper (JTR)** and **Networkwalks password-cracking tools**.

## Objectives

* Understand the process of extracting password hashes from protected PDF files.
* Configure and use John the Ripper through Johnny.
* Perform password-cracking attacks using extracted PDF hashes.
* Use Networkwalks Hash Calculator and Password Cracker.
* Verify successful password recovery from protected PDF files.

---

## Module 1 — John the Ripper

### Tools Used

* John the Ripper
* Johnny
* OnlineHashCrack for PDF hash extraction

### Methodology

1. Configured Johnny with the John the Ripper executable.
2. Extracted the password hash from the protected PDF.
3. Loaded the extracted hash into Johnny.
4. Started the password-cracking attack.
5. Verified successful password recovery.
6. Repeated the process for all three provided PDF files.

### Results

The password-cracking process was successfully completed for all three provided PDF files:

* **PDF1:** Successfully cracked
* **PDF2:** Successfully cracked
* **PDF3:** Successfully cracked

## Module 2 — Networkwalks Tools

### Tools Used

* Networkwalks Hash Calculator
* Networkwalks Password Cracker

### Methodology

1. Uploaded the protected PDF to the Networkwalks Hash Calculator.
2. Extracted the PDF password hash.
3. Copied the hash into the Networkwalks Password Cracker.
4. Started the password-cracking attack.
5. Verified successful password recovery.
6. Repeated the process for all three provided PDF files.

### Results

The password-cracking process was successfully completed for all three provided PDF files:

* **PDF1:** Successfully cracked
